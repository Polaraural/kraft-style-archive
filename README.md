# 我的设计档案袋 · 风格素材库

牛皮纸档案袋风格的个人视觉素材库，用来浏览、筛选和挑选可复用的视觉风格、动效与字体。

## 内容

- 23 个风格素材卡（工作台、官网、组件库、动效、字体等）
- 每张卡包含封面图、标签、适用场景、可提取元素、动效说明与色票
- 支持搜索、分类筛选、详情弹窗、随机抽卡和 4 格灵感板

## 访问

GitHub Pages：https://polaraural.github.io/kraft-style-archive/

## 本地预览

```bash
python3 -m http.server 8000
```

然后打开 http://localhost:8000/

## 目录

```
index.html      页面结构
style.css       牛皮纸视觉样式
app.js          素材数据与交互逻辑
assets/covers/  风格封面图
assets/fonts/   中文字体（Noto Sans SC / Space Mono）
```
